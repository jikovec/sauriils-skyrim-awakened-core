# Skyforge

Follow the public Core root AGENTS.md. This subtree owns Rust/Cargo installer, manifest, PEX and MO2 integration logic. Use locked synthetic tests from the repository root before changing behavior. Installer and MO2 commands can modify user state. Test those effects only with authorized disposable inputs. Keep exact fixtures, game installations and credentials out of commits. `skyforge checkpoint` captures and restores a save pair and a database dump as one [checkpoint](../../docs/engineering/checkpoints.md); it never restores over its source. Every archive passes [admission](../../docs/engineering/archive-admission.md) before install. Keep its refusals fail-closed and extend its synthetic fixtures with any change to extraction, staging or activation.
