# Security policy

**Development preview**: no supported public release of the complete Core runtime exists yet.

Use GitHub's private vulnerability reporting on this repository when available. Do not post exploit details, security credentials, connection tokens, personal saves or voice transcripts to public Issues. Report affected source and a non-sensitive reproducer privately. There is no guaranteed security-response SLA.

The project intends local-only AI services. A future portable release will document threat models and supported deployment choices explicitly.
