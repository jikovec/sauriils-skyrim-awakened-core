# Source promotion and publication

[Core rights](https://github.com/jikovec/sauriils-skyrim-awakened-core/issues/6), [Core portability](https://github.com/jikovec/sauriils-skyrim-awakened-core/issues/7) and [Collection reproducibility](https://github.com/jikovec/sauriils-skyrim-awakened/issues/1) are independent gates. A verified public source PR can advance engineering within the cleared boundary. A build proves neither file rights nor a portable installation.

1. Establish the authorized target repository, Issue, release intent and exact source revision or payload hashes. Classify each prospective file, dependency and generated artifact by origin, owner, rights, license and intended distribution. Record evidence and approval for third-party/derivative material under its own terms.
2. Exclude installed assets, models, voice files, saves, DB exports, private diagnostics, transcripts, credentials and uncategorized derivatives. Select specific cleared files in an isolated checkout of the verified remote. Never stage or sync the private workspace wholesale. Add notices and disclosures as needed.
3. Review the exact tree against its destination rights policy and source-only checks. Run local checks and inspect the staged/stored Git object list. GitHub secret scanning and hygiene checks cover common mistakes. Human rights approval still owns publication eligibility. Failed or uncertain provenance remains private.
4. Use a focused scoped PR, link required cross-repo changes, monitor exact-head checks and respect the current repository protections. For a distributable release verify reproducible acquisition and install separately, using only authorized source access and the qualified runtime recipe.
5. Retain a redacted public decision and a private source/rights receipt where warranted. Tag or publish a release only after its own authorization and acceptance. Preserve prior tags, manifests and historical verdicts.

Code, docs and reference data retain the destination [licensing terms](../../LICENSING.md) for original authored contributions. Mod licenses, AI training/distribution rights, lore corpora and voice performer consent remain distinct. Disable sensitive runtime payload capture by default. Confine services to the intended local interface and validate type, capability, identity and scope before execution. Generated actions cannot invoke arbitrary commands, scripts or SQL.
